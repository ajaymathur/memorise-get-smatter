## Description (4000)

```
Get Smarter is a set of four quick memory games based on experiments psychologists have used for decades. Each has Beginner, Advanced and Expert levels, so there's always a next step.

PAIR MATCH: Visual memory
Memorise the board, then find every pair. Based on classic concentration and visual pattern tasks.

SEQUENCE ECHO: Memory span
Watch the tiles light up and play the sequence back. Each tile has its own note. Expert asks you to play it in reverse. Based on the Corsi block-tapping task.

N-BACK: Working memory
Does this square match the one from N steps ago? Expert adds spoken letters at the same time: the dual n-back task.

WORD RECALL: Word memory
Study a list, then pick out the words you saw. Watch out for words that only feel familiar. Based on retrieval-practice and false-memory research.

DAILY TRAINING
A five-minute circuit through all four games that adapts to you. Two successes raise the level, a miss lowers it. Build a daily streak.

HONEST SCIENCE
Every game shows the research it's based on, with full citations. Practising these tasks makes you better at them. Whether that carries over to everyday memory is still debated, and we say so.

PLAY YOUR WAY
• Works completely offline, with no account needed
• Optional Game Center leaderboards (global and friends, all-time and weekly) and achievements
• Progress syncs across your devices with iCloud
• Full VoiceOver support, including the games themselves
• Relaxed timing, Reduce Motion, Dark Mode, and color-blind-friendly design
• No ads, no tracking, no data collected

For entertainment and education only. Not a medical product.
```
