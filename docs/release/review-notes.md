# Notes for App Review

Paste into App Store Connect → App Review Information → Notes.

```
Thanks for reviewing Get Smarter: Memory Games.

• No login or account is required. Every game works fully offline.
• Game Center is optional. Leaderboards and achievements appear only if the device is signed in to Game Center AND the player agrees to share scores (a one-time prompt after the first ranked game, also in Settings → Share scores on leaderboards).
• Progress syncs via the user's private iCloud (CloudKit) database. The app itself makes no network requests. No analytics, ads, or third-party SDKs.
• All sounds are synthesized on-device. Spoken letters in N-Back Expert use the on-device speech synthesizer.
• Research claims: the app says games are "based on" published research tasks, shows full citations (Settings → The Science), and states that evidence for everyday benefits is mixed. It makes no medical or cognitive-improvement claims.
• Notifications: only a local daily reminder, requested only when the user turns it on in Settings.

To see every level quickly: Settings → Unlock all levels.
```

Demo account: not needed.
